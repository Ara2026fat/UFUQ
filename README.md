# أُفق

تدريب يوميّ قصير على اختبارات القدرات والتحصيلي وستيب.
تطبيق ويب واحد، بلا خادم وبلا حساب — كلّ التقدّم على جهاز الطالب.

![أُفق](banner.png)

---

## الملفّات — كلّها مطلوبة، وكلّها في الجذر

| الملفّ | لماذا |
|---|---|
| `index.html` | التطبيق كاملًا، وبنك الأسئلة داخله |
| `manifest.webmanifest` | **بدونه لا يظهر خيار التثبيت إطلاقًا** |
| `sw.js` | العمل بلا إنترنت، وبدونه لا يعرض كروم زرّ التثبيت |
| `icon-192.png` | أيقونة أندرويد |
| `icon-512.png` | أيقونة الشاشات عالية الدقّة ومتجر التطبيقات |
| `icon-maskable.png` | أيقونة أندرويد المقصوصة — بلا كلمة، لئلّا تُقطع |
| `apple-touch-icon.png` | أيقونة آيفون عند «إضافة إلى الشاشة الرئيسية» |
| `favicon.png` | أيقونة تبويب المتصفّح |
| `banner.png` | لافتة المستودع — للعرض فقط، لا يحتاجها التطبيق |
| `README.md` | هذا الملفّ |

> **لا تضعها في مجلّدات فرعية.** المسارات نسبية، وأيّ نقل يكسر التثبيت.

## الرفع على GitHub Pages

1. مستودع جديد باسم `ufuq` — **عامّ (Public)**، لأن Pages المجّانية تشترط ذلك.
2. `Add file → Upload files` ← اسحب **الملفّات العشرة** (لا المجلّد نفسه) ← `Commit`.
3. `Settings → Pages` ← Source: **Deploy from a branch** ← Branch: `main` ← Folder: `/ (root)` ← `Save`.
4. انتظر دقيقة أو دقيقتين. الرابط:
   `https://<اسمك>.github.io/ufuq/`

GitHub Pages تعطي HTTPS تلقائيًّا — وهو شرط لازم للتثبيت وعامل الخدمة.

### التحديث لاحقًا
ارفع `index.html` الجديد فوق القديم، **وارفع رقم النسخة في `sw.js`**:
`const V = 'ufuq-v2';` — بدون هذا يبقى القديم في ذاكرة الأجهزة.

## التثبيت عند المستخدم

**أندرويد (كروم/إيدج):** يظهر زرّ «ثبّته» داخل التطبيق بعد أول جلسة، ودائمًا في
`الإعدادات ← المظهر ← التطبيق على جهازك`. البطاقة هناك تبيّن الحالة بنقطة ملوّنة:
خضراء **مثبَّت** · ذهبية نابضة **جاهز للتثبيت** · ذهبية ثابتة **آيفون**.

**آيفون (سفاري):** لا واجهة برمجية للتثبيت في iOS — الخطوة يدوية:
زرّ المشاركة ⇧ ← «إضافة إلى الشاشة الرئيسية». التطبيق يشرحها ويكتشف إن كان مثبَّتًا فيصمت.

## البيانات

كلّ شيء في `localStorage` تحت المفتاح `ufuq.v1`، على الجهاز وحده.
لا خادم، ولا حساب، ولا بيانات تُرسل إلى أيّ جهة.
مسح بيانات الموقع من المتصفّح يمسح التقدّم.

## تشغيل محلّي

`file://` لا يسمح بعامل الخدمة ولا بالتثبيت. للاختبار:

```bash
python3 -m http.server 8000
# ثم افتح http://localhost:8000
```
